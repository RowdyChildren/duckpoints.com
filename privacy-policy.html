Privacy Policy

Effective August 15, 2026  ·  Last updated August 15, 2026

This Privacy Policy describes how DuckBot (Discord Application ID 620003435961647164) collects, uses, stores, and protects information when you interact with the Bot on Discord. By adding DuckBot to a server or interacting with it, you acknowledge that you have read and understood this policy.

1 Who We Are

DuckBot is operated by Duck Bot LLC, a Tennessee limited liability company ("the Operator," "we," "us," or "our"). Configuration and administration of the Bot are handled through Duck Points LLC. For any privacy-related questions or requests, contact us at duckpoints@tomatoduck.com.

2 Information We Collect

DuckBot is a points-tracking ("karma") bot. It collects only the limited information necessary to record and attribute points.

2.1 Message Content (Message Content Intent)

DuckBot uses the Message Content privileged intent solely to detect point-award commands (for example, @goodstuff++) and to identify the entity receiving points. We do not store full messages. From a qualifying message, we retain only the identifier of the entity receiving points:

  • If the entity is a word or phrase (e.g., goodstuff), we retain only that literal string.
  • If the entity is a Discord user, we retain only that user's Discord user ID — not their username, message, or any other message content.

No other portion of any message is stored.

2.2 User Identifiers (Server Members / Guild Members Intent)

DuckBot uses the Server Members privileged intent to resolve referenced users to their Discord user IDs so that points can be correctly attributed. We collect:

  • The Discord user ID of the entity receiving points, when that entity is a user (retained as part of the point record — see Section 5).
  • The Discord user ID of the user who assigns points, for the purpose of identifying who awarded points to an entity (retained for 28 days — see Section 5).

2.3 Server Identifiers

We collect and retain the Discord server (guild) ID for the purpose of assigning and scoping points to the correct server.

2.4 Points Data

We store the point values associated with each tracked entity within a server.

2.5 Information We Do Not Collect

DuckBot does not collect or store presence information, online status, activity data, usernames, email addresses, IP addresses, voice data, or the content of any message beyond the entity identifier described in Section 2.1.

3 How We Use Your Information

We use the information described above solely to:

  • Detect point-award commands and record point assignments.
  • Attribute points to the correct entity within the correct server.
  • Identify, for a limited period, who assigned points to an entity.
  • Maintain and display point totals.

We do not sell your data, and we do not use your data for advertising, profiling, or any purpose unrelated to the Bot's point-tracking functionality.

4 Data Storage and Security

DuckBot is hosted on Microsoft Azure. All information collected by DuckBot is encrypted at rest. We apply reasonable technical and organizational measures to protect the data we hold. However, no method of transmission or storage is completely secure, and we cannot guarantee absolute security.
